## Session goal
Build the Facebook extension for the Social/Promotions feature (Page connection, photo posts, Reels), mirroring the existing Instagram integration; then fix a bug where nothing was actually publishing and make the requested Draft-tab UI changes.

## Decisions
- Facebook Page publishing uses the same Meta app (`META_APP_ID`/`META_APP_SECRET`, App ID `855184217393728`) already used for WhatsApp — not a new app. Required adding the **"Manage everything on your Page"** use case (Pages API) in the Meta dashboard to unlock `pages_show_list`, `pages_manage_posts`, `pages_read_engagement`; `pages_read_engagement` is shared with the existing Instagram use case (expected, not a conflict).
- Multi-Page handling: if `/me/accounts` returns exactly one Page, auto-connect it silently; if multiple, show a one-time picker at Connect time (not per-publish) so every subsequent publish needs zero extra steps. Chosen over connect-then-pick-per-publish because Page access is one-time per person/Business Manager, not per-post.
- Page access tokens for **unselected** Pages are stashed as JSON in the `social_connections.access_token` column (not in `extra`), because `get-social-status` only ever selects `extra` — this guarantees Page tokens never reach the browser even transiently during multi-Page selection.
- Facebook photo posts publish in a single call (`POST /{page-id}/photos`) — no container/polling step, unlike Instagram. Facebook Reels use the resumable-upload API (`start` → `transfer` via a `file_url` header so Meta fetches the hosted video server-side, no bytes proxied through the edge function → `finish` → status poll) — a genuinely different shape from Instagram's create-container/media_publish flow, so it wasn't reused verbatim.
- `PublishWorkflowModal.tsx` was generalized from Instagram-only to loop over every platform in `LIVE_PLATFORMS` (now `['instagram', 'facebook']`), publishing photo then Reel per platform, with each leg failing independently so one platform's error doesn't block another.
- Restructured Social page navigation: single **Promotions** top-level tab now wraps Featured/+Create/Draft/Published as a nested sub-tab row, sitting alongside Connections and Competitors — reduces top-tab clutter now that there are more platform-related tabs.
- Draft cards redesigned to 3 icon buttons (Send/Edit/Delete) instead of the old read-only list — this was also the actual fix for the "nothing publishes" bug (see below), not just a cosmetic ask.
